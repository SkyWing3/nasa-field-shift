# Frontend de Raíz

Antes de diseñar o modificar una pantalla, leer [DESIGN.md](DESIGN.md). Es la referencia acordada con Franco: estética editorial de campo basada en Vital Farms, marcos con carácter y navegación horizontal superior. Aplicarla a componentes, estados y móvil.

No reintroducir barra lateral, A/A+/A++, tarjetas genéricas redondeadas ni modo oscuro. Las preferencias de lectura viven en Configuración con nombres claros. No afirmar que las fuentes libres son las comerciales exactas ni que existe una skill personal instalada.

Leer los JSON publicados por Dev 2; no recalcular ciencia en componentes. No fabricar datos NASA, audios, indicadores o ganadores. Conservar límites, unidades, n y procedencia. No sobrescribir cambios concurrentes del backend.

Verificar escritorio, móvil, teclado y texto Muy grande. Ejecutar npm run test:integration. Dejar el proyecto sin commit ni push: Franco los realizará.
