# Continuidad del proyecto Raíz

Leer `README.md`, `plan-equipo.json`, `contracts/README.md` y
`docs/dev2/CONTINUAR.md` antes de trabajar. Consultar estado y decisiones en
`docs/dev2/PROCESO.md`. Dev 2 es Nicole.

El módulo `raiz_delivery` es una base local con fixtures; no afirmar que es
un pipeline científico terminado. Reproducir `python scripts/check_dev2.py`
al cambiarlo y registrar límites y pendientes. No editar salidas de `build/` a mano.

`server.py` y `team.sqlite3` pertenecen al centro de coordinación. No convertirlos
en API o base agrícola. No introducir FastAPI si no existe integrado previamente.
No inventar datos NASA/NOAA, coordenadas, revisiones humanas, MP3, emisiones,
pronósticos ni funcionalidades retiradas. Preservar evidencia y builds coherentes.
